# Rendered Fits

Sizing-led virtual try-on for Shopify fashion brands. Shoppers get a size answer from the brand's own size chart,
a photo try-on and complete-the-look on the product page.

- Website: https://www.renderedfits.com/
- Shopify app: https://apps.shopify.com/rendered-fits-virtual-try-on
- Open data (CC BY 4.0, each with a Zenodo DOI): [Shopify Size Chart Report 2026](https://doi.org/10.5281/zenodo.24165866),
  [sizing information by category](https://doi.org/10.5281/zenodo.24165871), [AI Sizing Study 2026](https://doi.org/10.5281/zenodo.24165873)
  and [UK size 12 measurements](https://doi.org/10.5281/zenodo.24165875). Files: [fashion-sizing-open-data](https://github.com/renderedfits/fashion-sizing-open-data).
  Summary: [Clothing Size and Fit Statistics 2026](https://www.renderedfits.com/clothing-size-statistics-2026/). Also the
  [Fashion Returns Index 2026](https://www.renderedfits.com/fashion-returns-index-2026/)
- Free tools: [clothing size converter](https://www.renderedfits.com/clothing-size-converter/),
  [size chart template](https://www.renderedfits.com/how-to-make-a-size-chart/)
